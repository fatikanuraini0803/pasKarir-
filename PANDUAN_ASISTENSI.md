

## Demonstrasi Decision Tree
1. Import ulang `backend/php/database.sql` hanya pada database uji/kosong (skrip membuat ulang tabel aplikasi yang sudah ada).
2. Login sebagai Super Admin dan buka menu **Analisis Decision Tree**. Tunjukkan distribusi 4 kelas, entropy, information gain, struktur pohon, serta confusion matrix.
3. Login sebagai User dan buka menu **Kebutuhan Pelatihan** untuk memasukkan profil dan mencoba prediksi.
4. Jelaskan bahwa dataset berisi 60 baris; evaluasi memakai 48 data latih dan 12 data uji secara stratified. Akurasi harus dibaca bersama ukuran data yang kecil.
